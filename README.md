# 盾を構えとけば何とか凌げる - Prototype 01

スマホのブラウザで遊ぶ見下ろし型アクションの試作です。

## 起動
`index.html` をブラウザで開くだけです。GitHub Pages にそのまま置けます。

## 操作
- 左スティック: 移動
- 盾: 長押しで防御。正面のかなり広い範囲を防ぎ、防御中はHPが徐々に回復
- 剣/武器ボタン: タップで攻撃、長押しでチャージ攻撃
- ジャンプ: 高く跳び、空中では敵の攻撃をすり抜ける
- スキル: ダッシュ攻撃
- チェンジ: 剣 → 槍 → ハンマー → 赤杖 → 青杖

PC確認用:
- WASD / 矢印: 移動
- J: 盾
- K: 攻撃
- L: ジャンプ
- I: スキル
- Q: 武器チェンジ

## 武器ギミック（試作）
- 剣: 草を斬る
- 槍: 遠いスイッチを押す
- ハンマー: 岩を壊す
- 赤杖: 草を燃やす
- 青杖: 水を一定時間凍らせる

## 今回の狙い
まずは「困ったら盾を構えれば本当に何とかなる」という感触を最優先しています。
キャラクター、敵、仕掛けは太い黒線で描画し、スマホ画面でも判別しやすくしています。
